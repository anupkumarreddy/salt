# Security Policy

## Supported Versions

SALT is pre-1.0 software. Security fixes are handled on the latest release line.

## Reporting a Vulnerability

Please report security issues privately by contacting the maintainer instead of opening a public issue. Include:

- A description of the issue and affected versions.
- Steps to reproduce or a proof of concept, if available.
- Any known impact or workaround.

The maintainer will acknowledge valid reports and coordinate a fix before public disclosure.
